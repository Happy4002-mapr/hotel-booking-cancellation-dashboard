# Hotel Booking Cancellation Analysis Dashboard

## Project Overview
An interactive hotel booking analysis dashboard created using Microsoft Excel to analyze booking performance, cancellation trends, guest types, and room preferences.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Excel formulas and data visualization

## Key Performance Indicators (KPIs)
- Total Bookings: 119,390
- Cancelled Bookings: 44,224
- Cancellation Rate: 37.0%
- Successful Bookings: 75,166

## Dashboard Features
- Bookings by Guest Type
- Bookings by Room Status
- Bookings by Hotel Type
- Monthly Bookings vs Cancelled Bookings
- Year filter using a slicer
- KPI cards for key booking metrics

## Key Insights
- The overall cancellation rate is approximately 37%.
- The dashboard compares booking patterns across guest and hotel categories.
- Monthly comparisons help identify changes in booking and cancellation volumes.
